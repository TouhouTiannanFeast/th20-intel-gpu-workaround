# TH20 Intel GPU startup workaround

为《东方锦上京》TH20 的 `th20.exe` 设置 Windows **高性能显卡偏好**，供 Intel 核显与 NVIDIA/AMD 显卡并存的 Windows 10/11 电脑尝试绕过核显路径中的启动崩溃。

参考案例为 TH20 1.00c 在 `igd9trinity32.dll`（驱动 `32.0.101.8331`）中发生 `0xc0000005` 访问冲突。设置高性能显卡偏好后恢复启动。这个工具提供绕过方案，没有修改或修复 Intel 驱动；实际显卡选择由 Windows 决定，只有 Intel 显卡的电脑不适用。

## 使用

1. 下载仓库 ZIP 并解压到可写的普通文件夹。
2. 完全退出 TH20。
3. 双击 **Apply.cmd**，选择游戏实际的 **th20.exe**。
4. 重新启动游戏，检查画面、声音及进入关卡是否正常。

无需管理员权限。保留整个工具目录，以便回退。若已经设置高性能显卡，本工具提示无需修改。

## 回退

双击 **Restore.cmd**，选择原来相同路径的 `th20.exe`。工具恢复首次应用前的显卡偏好。若偏好后来被其他工具修改，回退会停止，以保留新设置。

游戏移动到新路径后，需要对新路径重新应用。

## 修改与隐私

仅修改当前用户注册表 `HKCU\Software\Microsoft\DirectX\UserGpuPreferences` 中以所选程序完整路径为名的字符串，设置 `GpuPreference=2;`，保留该字符串内的其他字段。

- 不修改游戏程序、驱动、存档或窗口位置，不自动关闭游戏。
- 不联网，不上传信息，不收集机器标识。
- 本地 `backups/` 保存游戏完整路径、原偏好和操作时间，用于回退。**请勿上传或转发该目录。** 仓库已将其排除。
- 公开报告保留排障所需的游戏版本、故障模块、驱动版本、异常码和偏移；不含用户名、个人路径、精确显卡型号或原始日志。

启动脚本的执行策略选项仅作用于本次 PowerShell 进程，不更改系统执行策略。

## 验证范围

脚本通过语法检查、只读状态查询和不写入的预演；参考电脑使用相同的设置恢复了启动。尚无其他硬件的兼容性验证，也未完成驱动根因分析。它不处理“有音乐但窗口在屏幕外”的另一个问题。
